# `gatsby-nanogpt-3` — frozen release (v3)

A self-contained, runnable snapshot of the exact code that produced this
model, with no dependency on the project root or the shared `core/` engine (see
[ADR-0003](../../../../docs/adr/0003-frozen-self-contained-releases.md)).

The first gatsby release on the modern engine with a byte-level BPE
([ADR-0023](../../../../docs/adr/0023-gatsby-migrates-to-core-bpe.md)): 6L/6H/384E,
256-token context, 1,024-token vocabulary, ≈11.0M parameters. Trained on the whole
train split of [tiny-green-light-stories v3](https://huggingface.co/datasets/sup-computer/tiny-green-light-stories)
(25,499 stories written by DeepSeek V4.1 Flash), the winner of a size sweep over
5k / 10k / full subsets (internal name: `v3-full`; evidence in `../../research/log.md`).

| File | Role |
|---|---|
| `prepare.py` | downloads the dataset at tag `v3` from Hugging Face, keeps the subset named in `config.py`, prefixes each story with its control line, encodes with the pinned tokenizer → `data/{train,val}.bin` + `data/meta.pkl` |
| `data/tokenizer.json` | **pinned**: the 1,024-token byte-level BPE trained on the v3 train split. Never retrained here |
| `model.py`, `train.py`, `checkpoint.py`, `configurator.py`, `sample.py` | vendored copies of the shared engine, imports localized; `train.py` runs from its own folder and reads `config.py` with no arguments |
| `config.py` | the exact released hyperparameters (8,000 iters, best val at 7,750) |

The corpus was written by an LLM, so it cannot be regenerated byte-for-byte; the
Hugging Face dataset at tag `v3` is its record. `prepare.py` rebuilds the
release's `train.bin` and `val.bin` byte-identical to the ones it trained on
(checked at release).

## Rebuild in place

```bash
cd projects/gatsby/models/gatsby-nanogpt-3
uv run python prepare.py        # needs network (Hugging Face)
uv run python train.py          # ~0.45 s/iter on an Apple M-series GPU; ~70 min
uv run python sample.py --out_dir=. --data_root=. \
  --start=$'[green=4] [green=4] [green=4] obsession=heavy\ntopic: a boat on the lake\n' \
  --num_samples=1 --max_new_tokens=250
```

The control line's shape is a contract (`projects/gatsby/generate.py:build_prime`);
`prepare.py` carries a verbatim copy.
